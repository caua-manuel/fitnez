# Superpowers — índice local

Este arquivo é um índice de organização do projeto. As instruções oficiais
permanecem intactas nas subpastas `./skills/` e em `../../../.claude/skills/`.

Comece por `./skills/using-superpowers/SKILL.md` e leia as skills pertinentes:

- `brainstorming/SKILL.md`: explorar requisitos e direção.
- `writing-plans/SKILL.md`: detalhar planos de implementação.
- `executing-plans/SKILL.md`: executar planos.
- `dispatching-parallel-agents/SKILL.md`: distribuir trabalho independente.
- `subagent-driven-development/SKILL.md`: implementação com subagentes.
- `using-git-worktrees/SKILL.md`: isolamento de trabalho com Git.
- `test-driven-development/SKILL.md`: desenvolvimento orientado por testes.
- `systematic-debugging/SKILL.md`: investigação de falhas.
- `verification-before-completion/SKILL.md`: verificar antes de concluir.
- `requesting-code-review/SKILL.md`: solicitar revisão.
- `receiving-code-review/SKILL.md`: tratar revisão recebida.
- `finishing-a-development-branch/SKILL.md`: finalizar uma branch.
- `diagnosing-superpowers/SKILL.md`: diagnosticar o próprio Superpowers.
- `writing-skills/SKILL.md`: criar e manter skills.

Os caminhos da lista são relativos a `./skills/` nesta pasta. Recursos auxiliares
estão junto de cada skill. A cópia para consulta direta de debugging fica também
em `../../testes-debug/systematic-debugging/`.
